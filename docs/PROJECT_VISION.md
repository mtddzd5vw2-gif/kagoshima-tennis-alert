# Tennis Court Watcher プロダクトビジョン

## サービス名

**Tennis Court Watcher（テニスコートウォッチャー）**

---

# ミッション

全国の公共施設予約システムをもっと便利にする。

利用者が毎日何度も予約サイトを確認する必要をなくし、
本当に空きが出た瞬間だけ通知を受け取れる世界を実現する。

---

# ビジョン

鹿児島から始まり、

- 九州
- 全国主要都市
- 全国の公共施設

へ展開し、

「公共施設の空き状況通知サービス」のデファクトスタンダードになる。

---

# なぜ作るのか

公共施設予約サイトは

- 見づらい
- 更新頻度が低い
- 毎日チェックが必要
- 空きが出ても気付けない

という課題がある。

私たちは

「空きが出たら教えてくれる」

というシンプルな価値を提供する。

---

# コアコンセプト

利用者は

> 「予約サイトを見る」のではなく
> 「通知を待つ」

だけでよい。

---

# 最初のターゲット

鹿児島市テニスコート

対応施設

- 鴨池県営
- SuMIzei
- 東開庭球場

---

# 将来の展開

テニスだけではなく、

- 体育館
- 野球場
- サッカー場
- 会議室
- 多目的施設
- キャンプ場
- プール

など公共施設全体へ拡張する。

取得部分（スクレイパー）だけ差し替えれば、
通知エンジン・会員管理・UIは共通利用できる構成を目指す。

---

# MVP（最初に公開する機能）

- 空き状況表示
- LINE通知

- 通知条件設定
- マイページ

# 開発方針

設計は全国展開を前提とする。

ただし実装は

**Small Start**

を徹底する。

鹿児島市で完成させ、

運用し、

改善し、

その後に福岡・東京・全国へ展開する。
